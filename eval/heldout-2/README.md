## What round 2 shows

**The fixes did not measurably improve the checker on new papers.** On the same 12 edited papers, the current pipeline and round 1's pipeline catch almost the same planted errors (89 vs 87, p = 0.75) with the same reviewed precision (60% vs 61%). The rise from round 1's 80% / 54% to 86% / 60% comes from the papers drawn, not from the fixes; without the paired run it would have looked like progress.

What the fixes did change, on the same papers:

- **Labels.** Label accuracy on planted errors rose from 67% to 84%, and 4 more citation swaps were caught (53 vs 49 of 54): swapped citations are now called "not found" instead of being softened by the identification leniency.
- **Inputs.** Table contents now reach the judge (Verbitsky et al.'s 32.6% and the 39-qubit paper's error table are read), and arXiv versions are checked against publication years.
- **Not precision.** The two pipelines raise different false alarms (26 only by the current one, 22 only by the old one) but about the same number. The prompt rules for method, data-source and co-cited citations removed some false alarms and the judge produced others.

Both pipelines missed all 4 hedge removals, and the current one caught 2 fewer scope inflations (27 vs 29 of 34).

## Findings for the next fixes

These papers have now been examined in detail, so the next fixes need a round 3.

Of the 93 false alarms (either pipeline), the recurring causes:

- **Derived values credited to a data source.** "The M ∝ M⋆^1 relation we get for the (Manara et al., 2022) sample", "linear regression on the Class I VLA data from (Tobin et al., 2020) yields ...". The citing authors computed these from the cited data; the judge looks for the value in the cited paper. 6 of the planet-formation paper's false alarms are of this kind.
- **Comparisons and applications by the citing authors.** "Consistent with the result in [45]", "the unit normal vector can be written as [32]" (the cited general formula in the citing authors' notation). The prompt rule on comparisons did not stop these.
- **Co-cited works.** Several two- or three-work citations are still judged as if each work had to support every part.
- **Number-drift misfires (5).** Parsing errors ("10−17" in PDF text is 10^-17 with the superscript lost, read as 10; "≈1800 −2000 K" read as two numbers) and pairs of different quantities (an isolation mass against a critical core mass; dataset inclusion criteria against gnomAD).
- **Abstract-only references.** The abstract-only rule softens "not found" but not "overstated", so a detail missing from an abstract still raises a flag.
- **Reasoning slips.** A unit conversion the judge did not do (Birnstiel et al.'s n(m)·m·a exponents are exactly the cited St^-0.5 and St^-0.75), and a synonym it did not know (colon carcinoma kinase-4 is PTK7's original name).
- **Checker inputs.** A textbook resolved to a journal book review with the same title (Kline's SEM book).

**Coverage limitation found during screening.** Papers whose bibliographies print no titles (AAS and REVTeX styles: "Allard, F., et al. 2007, ApJ, 474, L21"; REVTeX's bare arXiv IDs) cannot be resolved at all, so they fail the coverage criterion and are never checked.

**Genuine problems found in the original papers (20 citations in 9 papers).** Examples:

- Wrong references:
  - a sample-size methods paper cited for what PRNT measures;
  - a study of PTSD in college students cited for Syria's third COVID-19 wave;
  - a video-games review cited for sedentary lifestyle and sleep;
  - a Pauli-measurement paper cited as a tensor-network decoder;
  - a review cited "as described previously" for an image-analysis method it does not contain.
- Wrong numbers:
  - 20.5% for a reported 24.5% (twice);
  - 29.4% and 12.6% prevalences that appear nowhere in the cited papers;
  - a 39% prevalence said to agree with a study that found 1.07%.
- Reversed or overstated findings:
  - lockdowns said to worsen domestic-labour inequality, citing a study that found it static or slightly more equal;
  - supplements called a vital nutrient source, citing a review that finds them unnecessary with a balanced diet;
  - preclinical antiviral activity reported as "effective treatments";
  - a 3D surface-code scaling claim that the cited paper explicitly leaves open.

Only 17 of these were flagged by the current pipeline and 19 by the old one: each found some the other missed.

## Deviations and caveats

- **Screening restarted once.** The first attempt was discarded before anything was planted: Crossref refused about 280 lookups and an OpenAlex request failed, so some low-coverage rejections were unsound and both psychology samples came back empty. Screening now marks such candidates inconclusive and pauses their stratum.
- **The rule was refined during screening.** A candidate is inconclusive only if success on every failed lookup could lift its coverage to 50%. This settled two candidates stuck on one failed lookup each, at 29% and 23% coverage.
- **OpenAlex quota.** Screening was paused for a day when the daily OpenAlex budget ran out.
- **No eligible computer-vision paper** in 71 candidates (almost all cite mostly paywalled work). Both psychology strata were filled this time.
- **Planting mix.** Citation swaps (54 of 103) and scope inflations (34) dominate; only 11 number changes and 4 hedge removals could be planted.
- **One reviewer.** Every flag from either pipeline was reviewed by one reviewer (Claude, reading the cited text), with 53 of 166 marked debatable and left out of precision.
- **Old pipeline as built.** The comparison runs round 1's code with its own reference resolution, so it includes the resolver fixes as well as the judge changes; both pipelines see the same edited papers.
